# Google Play Data Safety Evidence

## Status and use

Evidence snapshot: 2026-08-27.

This is an engineering worksheet for the production Android package declared in [`android/app/build.gradle.kts`](../../android/app/build.gradle.kts). It is not a legal conclusion, a Play Console export, or proof that any declaration has been submitted. No AdMob, Google Cloud, Play Console, Supabase dashboard, Sentry organization, release artifact, or physical device was inspected while preparing it.

Google Play requires the publisher to account for off-device collection by application code and every included SDK, including pseudonymous and ephemeral processing. Whether a transfer is “shared,” whether an exception applies, and which purposes are selected can depend on contracts and actual production configuration. The operator remains responsible for the final answers. Use the current [Play Data safety instructions](https://support.google.com/googleplay/android-developer/answer/10787469) when completing the form.

Status values in this worksheet mean:

- `Repository evidence`: the linked source or test establishes the stated application behavior.
- `External source`: a provider's current published disclosure, not a finding about the exact release artifact.
- `TBD — operator`: requires console access, an exact built artifact, provider terms, hosted configuration, device testing, or a policy/legal decision.
